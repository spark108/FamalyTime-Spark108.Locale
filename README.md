# Spark108.Locale

## Description / Описание

Модификация добавляет возможность локализировать интерфейс игры. В данный момент присутствует русский язык.

Для создания своей локализации достаточно скопировать файл русского языка и перевести фразы на свой язык.

Ключ фразы — это её оригинальный текст в игре. Если в игру добавятся новые наименования, то достаточно добавить ключ в файл локализации и перевод для вашего языка.

Модификация также позволяет переводить фразы, добавляемые другими модами.

Добавлены фразы из следующих модов

- Pup Trampolines

This modification adds the ability to localize the game's interface. Russian is currently supported.

To create your own localization, simply copy the Russian language file and translate the phrases into your desired language.

The key for each phrase is its original text as it appears in the game. If new terms or labels are added to the game, you can simply add the corresponding key and its translation to your localization file.

The modification also allows for the translation of phrases added by other mods.

Phrases added from the following mods

- Pup Trampolines

This text has been translated into English using Google Translate.

## Installation instructions / Инструкция по установке

1. Установите Family Time Mod Manager и распакуйте архив в папку `plugins`.
2. Для изменения языка игры отредактируйте файл `config.json`, указав в нём нужный перевод.

---

1. Install Family Time Mod Manager and extract the archive into the `plugins` folder.
2. To change the in-game language, edit the `config.json` file and specify the desired translation.
